первый коммит: добавление ввода переменных и операции сложения

второй коммит: добавление отрицания

третий коммит: добавление умножения



git diff - показывает что я изменил сейчас

git show - показывает изменения коммита

git log - показывает все изменения, типо истории



git restore - возвращает файл к последнему коммиту
git restore --source=... - возвращает к конкретному указанному коммиту

git reset --hard - убивает последний коммит, возможны дальнейшие конфликты файлов
git revert - отменяет коммит и не ломает историю
